# Plan: run-many-machines step 3 uses Scope and Exit values that step 2 does not import (#579)

On the tea how-to page "Run many machines", the step 3 snippet calls `Scope.make`, `Scope.close` and `Exit.void`. Step 2's import block only imports Scope as a type and doesn't import Exit, so pasting step 3 under step 2 doesn't compile. Step 3 also isn't held by the page's source check, which is how the gap got through. Step 2 is a copy of an example file and has to stay one, so the fix is to give step 3 its own imports and back it with compiled source that the page must show exactly. After that, step 3 compiles as written, and any import that goes missing later fails a test.
