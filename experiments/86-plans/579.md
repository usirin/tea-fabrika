# Plan: run-many-machines step 3 uses Scope and Exit values that step 2 does not import (#579)

On the how-to page "Run many machines under one parent", step 3 ("Use it") calls `Scope.make()`, `Scope.close` and `Exit.void`. It has no imports of its own, and step 2, which it builds on, imports `Scope` as a type only and does not import `Exit` at all. A reader who pastes step 3 under step 2 gets compile errors. After the fix, step 3 compiles as shown: it imports everything it uses. It is also held by the same page-equals-source test as the page's other blocks, and the test runs it, so a missing import or any other drift fails a test.

Size: 2 stories, 1 task, 4 criteria, 777 words.

## User stories

- **s1**: As a developer following the run-many-machines how-to to build a tree of tea machines on Effect, I want to paste the page's step 3 next to steps 1 and 2 and have it compile and run as the page describes, so that so the page that teaches spawn, stop and tell gets them to a working parent and workers without guessing which imports are missing.
- **s2**: As a maintainer of @demlik/tea's docs, I want step 3's snippet to be checked against compiled source, like the page's other blocks, so that so a later change to the helpers or imports cannot leave the page's 'use it' step broken without a test failing.
