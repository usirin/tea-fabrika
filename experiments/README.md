# Experiment log

What we tried, what came back, and what we took from it. Every
number here came from a real run against Jev and, where it says so, Claude Code.
The samples are small and the two toys are tiny, so read these as hints, not
proof.

Guesses that turned out wrong are left in on purpose. One mistake cuts across
several experiments: read [section 16](./16-agents-had-a-shell.md) before
trusting any line that says an agent could not see a file.

## How this folder is laid out

- `NN-title.md` is the write-up of experiment NN. The numbers run in the order
  the experiments were done, 01 first.
- Scripts are not kept on main. On 2026-11-09 every experiment script, its `lib/` helpers and
  the five harness packages were removed. They are all on the branch
  `fabrikalfa/archive-2026-11-09`, and a write-up that names a script means that copy.
- Results and assets are not kept on main either
  ([0027](../.decisions/0027-experiment-results-live-in-a-private-archive.md)). On 2026-11-09
  every file here that was not a top-level write-up (`results/`, the `NN-name/` folders,
  `failures/`, shots, JSON and patches: 610 files, about 40 MB) moved to the owner's private
  archive, at the same paths. Git history holds every one too: a path a write-up names under
  `results/` or an `NN-name/` folder is at commit `423fb9cf`, as in
  `git show 423fb9cf:experiments/results/<file>`. Two files stay because code reads them:
  `results/86b-plans.json` and `177-themes/schemes/radix-colors-3.0.0.json`.
- A new write-up quotes the numbers it uses inline. Raw results and assets go to the private
  archive; a script writes raw samples under `runs/`, which git ignores, or to a path a flag names.
- The write-ups left here shrink over time: a write-up nothing cites goes once its lesson is in
  `.decisions/`, `.patterns/` or `docs/direction/`.
- [open-questions.md](./open-questions.md) is the list of open questions the
  log kept up to experiment 20.

## The setup

Two toys under `fixtures/`: `slugify` (three rules) and `duration`
(`parseDuration`, six rules). `lib/toys.ts` holds, for each toy, one correct
implementation and several broken on purpose, each breaking one criterion. That
is what gives a case a known answer: run the real tests and see.

Jev is a small classifier. It answers a multiple-choice question about some
JSON and returns a confidence between 0 and 1. The lane acts on an answer only
when the confidence is at or above a floor.

## The experiments

This folder keeps no table of its write-ups
([0522](../.decisions/0522-no-folder-keeps-an-index-table.md)). The lead's command prints one line
per write-up as it is on `origin/main`, then the next free number, which is the one a new write-up
takes:

```sh
node .agents/skills/lead/scripts/records.ts list experiments
node .agents/skills/lead/scripts/records.ts next experiments
```

A write-up opens with frontmatter above its `# ` heading. `date` is the day the write-up was
first committed. `summary` is the answer in one line: the version it is about, what it cost, and
what came back. `scripts` names what ran, and may be left out when the write-up names it itself.
Each value is one line, in double quotes:

```markdown
---
date: "2026-11-13"
scripts: "none; reading, nothing ran"
summary: "Both versions; $0. Yes, and the one case it misses is named."
---

# 288. The question, as a question?
```

Entries 39, 40, 41, 44, 45 and 46 say of themselves that they are not experiments: a change, a
run, a redesign, a data set. They keep their numbers because later write-ups point at them by
number. Write-ups 79, 80 and 81 never had a row, so they have no frontmatter yet.
