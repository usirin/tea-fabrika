# A made-up code rubric, for tests

This file is not a real rubric. It was written for this repo's tests, to stand
where a real one is read from at run time.

## Per criterion

Read the lines that meet each criterion. A criterion with no line to point at
is not met.

## Standing checks

- **tests-prove-it**: a test would fail if the change were taken out.
- **no-silent-catch**: an error that is caught is reported or handed on.
