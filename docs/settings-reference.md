# Settings reference

Every setting in the new version (`next/`), with its default and what it does. The list below is
generated from the declarations. Do not edit it by hand.

```sh
pnpm --filter @kampus/fabrika settings:generate
```

## Regenerate this page and the schemas

Run the command above from the repository's root after you add or change a setting. It writes three
files from the declarations:

- `next/apps/fabrika/person.json`, the schema for the person's file
- `next/apps/fabrika/repo.json`, the schema for a repo's file
- this page, only the part between the two `generated` markers

The words outside the markers stay as they are. Commit all three files with the change. A test
checks that the committed files match what the command writes.

## Let your editor check a settings file

An editor that speaks TOML, such as one with Taplo or Tombi, can complete, explain and check keys
from these schemas.

1. Copy `next/apps/fabrika/person.json` next to your own file, into `~/.fabrika/` (or
   `$FABRIKA_HOME` if you set it).
2. Copy `next/apps/fabrika/repo.json` next to a repo's file, into that repo's `.fabrika/` folder.
3. Put the matching line at the top of each file. The path starts at the file's own folder.

```toml
# ~/.fabrika/fabrika.toml
#:schema ./person.json
```

```toml
# .fabrika/fabrika.toml
#:schema ./repo.json
```

Nothing edits your files for you. Copy the schemas again after you update fabrika, since a new
setting only shows up in a fresh copy.
