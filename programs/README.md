# programs

One package per tea program that runs on its own: a name, typed flags, inputs and outputs, built
on `@tea-fabrika/tea-program`. A program here may use the packages in `packages/`, and nothing in
`wip/` or `legacy/`. Empty for now: the stage programs still live in `wip/` and come out one at a
time (see `experiments/82-monorepo.md`).
