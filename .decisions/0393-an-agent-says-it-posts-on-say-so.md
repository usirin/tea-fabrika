# 0393: An agent that posts something on a person's say-so says so in the post

**What this decides:** how a post an agent makes for a person reads.

## Context

From [nobody grades their own work](../docs/direction/nobody-grades-their-own-work.md#what-was-decided),
decided 2026-10-04. Its "no agent approves" is already [0071](0071-risk-tier-decides-who-looks.md)'s
and AGENTS.md's.

## Decision

**A post an agent makes because a person said so names that it was on their say-so.**

- No agent approves. When an agent posts on a person's word, the post says so, so nobody takes it
  for the agent's own judgment or for the person's own post.

## Consequences

- A reader can always tell an agent's post from a person's.
